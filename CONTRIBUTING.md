# Contributing

Thanks for your interest in improving generator-markdown-to-html!

## Development

```bash
npm install
npm run typecheck
npm test
npm run build
```

## Pull requests

- Open a focused PR (one feature / fix per PR when possible).
- Include tests for new behavior.
- Update the README if the public API changes.
- Keep the function pure (no I/O, no logging).

## Commit messages

Use conventional commits where practical (`feat:`, `fix:`, `docs:`, `test:`, `chore:`).
